# AtherCare Quick Demo

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome.
3. Click **LOAD DEMO READINGS** to demonstrate simulated readings, or enter readings manually and click **UPDATE DASHBOARD**.

## Important
- The demo button generates simulated values; it does not read from the ESP32.
- This version does not connect to Firebase or any backend.
- Status thresholds are demonstration-only, not clinical guidance.
- The prototype is not a medical device and must not be used for patient care.
- Reading history is held in browser memory and clears when the page is refreshed.
